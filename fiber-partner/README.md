# Fiber Partner — LINE-only Landing Page

เว็บไซต์ภาษาไทย React + Tailwind CSS + Vite สำหรับแนะนำนายหน้าอินเทอร์เน็ตบ้าน มีแพ็กเกจ 499/599 บาท และค่าตอบแทนผู้แนะนำ 100 บาทต่อเคสที่ติดตั้งสำเร็จ

## ติดต่อทั้งหมดผ่าน LINE

ทุกปุ่มติดต่อใช้ URL นี้: https://line.me/ti/p/okGbiHWs0U

แก้ไขได้ที่ `src/config.js` → `lineUrl`

**ไม่มีฟอร์มเว็บไซต์, ไม่มี Netlify Forms, ไม่มีการเก็บข้อมูลลูกค้าบนเว็บ, ไม่มีฐานข้อมูล** — ผู้สนใจคุยและส่งข้อมูลที่ได้รับความยินยอมแล้วผ่าน LINE กับผู้ประสานงาน

## เปิดโปรเจกต์บนเครื่อง

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

ไฟล์ที่สร้างจะอยู่ใน `dist/`

## อัปเดตโปรเจกต์ GitHub เดิม

ถ้าโครงสร้าง Repository เป็น `3bb_partner/fiber-partner/` ให้อัปโหลดเนื้อหาในโฟลเดอร์ `fiber-partner` ของ ZIP ลงโฟลเดอร์เดียวกันบน GitHub แทนไฟล์เดิม แล้ว Commit

ตั้งค่า Netlify:
- Base directory: `fiber-partner`
- Build command: `npm run build`
- Publish directory: `dist` (ใน netlify.toml กำหนดไว้อยู่แล้ว)
- Package directory: ใช้ค่าเริ่มต้น/ตามโครงสร้างของโครงการ

ไม่จำเป็นต้องตั้งค่า Netlify Forms

## แบบอัปโหลดไฟล์ขึ้น Netlify โดยตรง (ไม่ใช้ GitHub)

ใช้ไฟล์ ZIP ชื่อ `fiber-partner-direct-netlify.zip` แยกต่างหาก ใน Netlify → Add new project → Deploy manually แล้วลากโฟลเดอร์ที่แตกไฟล์ลงช่อง Drag and drop (หรือคลาย ZIP ก่อนอัปโหลดตามหน้าจอ)

## ข้อควรตรวจสอบก่อนเปิดใช้งานจริง

- ราคาของ 499/599 บาท และอุปกรณ์แถมต้องได้รับการยืนยันจากผู้มีสิทธิ์เสนอขาย
- ตรวจสอบ VAT/สัญญา/เงื่อนไขเขตพื้นที่และความพร้อมการติดตั้ง
- ต้องแจ้งลูกค้าและขอความยินยอมก่อนส่งข้อมูลส่วนตัวผ่าน LINE
- ตกลงรอบจ่าย 100 บาทและเกณฑ์ตรวจสอบเคสกับนายหน้าให้ชัดเจน
- อย่าแสดงตนว่าเป็นช่องทางทางการของ AIS หรือ 3BB หากไม่ได้รับอนุญาต
