# Fiber Partner — Modern Clean Landing Page

เว็บไซต์หน้าเดียวภาษาไทยสำหรับรับข้อมูลลูกค้าที่สนใจติดตั้งอินเทอร์เน็ตบ้าน โดยผู้แนะนำมีสิทธิ์รับค่าตอบแทน **100 บาทต่อเคสที่ติดตั้งสำเร็จและผ่านการตรวจสอบ**

## เทคโนโลยี
- React + Vite
- Tailwind CSS
- Lucide icons
- Netlify Forms (ไม่ต้องสร้างเซิร์ฟเวอร์หรือใช้ฐานข้อมูลในเวอร์ชันนี้)
- รองรับจอมือถือ / แท็บเล็ต / เดสก์ท็อป

## เริ่มต้นบนเครื่อง
ต้องใช้ Node.js 20 ขึ้นไป และมีอินเทอร์เน็ตสำหรับติดตั้ง dependencies ครั้งแรก

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ http://localhost:5173)

**สำคัญ:** ฟอร์มในโหมด `npm run dev` จะไม่ส่งข้อมูลจริง แต่แสดงข้อความว่าอยู่ในโหมดทดลอง; ฟอร์มจริงจะใช้ Netlify Forms เมื่อเผยแพร่บน Netlify

## วิธีเผยแพร่บน Netlify (แนะนำ: เชื่อม Git)
1. เปลี่ยนค่าที่ `src/config.js` ตามหัวข้อ **เช็กลิสต์ก่อนเผยแพร่** ด้านล่าง
2. อัปโหลดโฟลเดอร์โครงการไป GitHub repository ของคุณ
3. ที่ https://app.netlify.com เลือก **Add new project → Import an existing project** และเชื่อม repository
4. ตั้งค่า **Build command:** `npm run build` และ **Publish directory:** `dist` (กำหนดไว้แล้วใน `netlify.toml`)
5. Deploy และไปที่ **Forms** ในแดชบอร์ด Netlify ตรวจว่าพบแบบฟอร์มชื่อ `fiber-lead`
6. ทดสอบส่งเคสด้วยข้อมูลทดสอบที่ไม่ใช่ข้อมูลส่วนบุคคลจริง ตรวจสอบว่าเคสเข้าที่ **Forms → fiber-lead** แล้วจึงใช้งานจริง

### อีกทาง: Netlify Drop
เมื่อมี Node.js บนเครื่อง ให้รัน:

```bash
npm install
npm run build
```

จากนั้น **ลากโฟลเดอร์ `dist` (ไม่ใช่ ZIP source code นี้)** ไปที่ Netlify Drop เพื่อเผยแพร่เป็น static site

## Netlify Forms ทำงานอย่างไร
- `index.html` มี hidden HTML form ที่ Netlify ใช้ตรวจจับฟอร์มตอน build
- ฟอร์ม React ใน `src/App.jsx` ส่ง POST แบบ `application/x-www-form-urlencoded` ด้วย `form-name=fiber-lead`
- ข้อมูลลูกค้าแสดงใน Netlify Forms ของเว็บไซต์นั้น
- เพิ่มการแจ้งเตือนทางอีเมลได้ใน Site configuration → Forms → Notifications (เมนูอาจปรับเปลี่ยน)
- มี honeypot field ใน HTML เพื่อลด spam แต่ควรเปิดระบบป้องกันเพิ่มเติมตามความเหมาะสม
- ตรวจสอบแพ็กเกจ Netlify รวมถึงข้อจำกัด/ค่าใช้จ่ายของ Forms ก่อนเปิดรับข้อมูลปริมาณมาก

## เช็กลิสต์ก่อนเผยแพร่จริง — สำคัญ
1. เปลี่ยน `operatorName`, `privacyEmail` และถ้ามี `lineUrl` ใน `src/config.js` เป็นข้อมูลผู้รับผิดชอบและช่องทางติดต่อที่แท้จริง
2. ปรับประกาศข้อมูลส่วนบุคคลใน `PrivacyDialog` ที่ `src/App.jsx` ให้ตรงการดำเนินงานจริง รวมถึงระยะเวลาเก็บ ข้อมูลผู้ควบคุมข้อมูล ช่องทางใช้สิทธิ์ และผู้รับข้อมูลตาม PDPA
3. ควรทดสอบและมีหลักฐานยืนยันว่าลูกค้ายินยอมให้แนะนำ/ติดต่อจริงก่อนบันทึกข้อมูลลูกค้า
4. กำหนดกติกาค่าตอบแทนเป็นลายลักษณ์อักษร เช่น จ่ายเมื่อใด เคสซ้ำ ยกเลิกงาน ช่องทางจ่าย และเงื่อนไขภาษีที่เกี่ยวข้อง
5. ตรวจสอบสิทธิในการใช้ชื่อบริษัท/เครื่องหมายการค้าของผู้ให้บริการ หลีกเลี่ยงการอ้างว่าเป็นเว็บไซต์ทางการหรือคู่ค้าทางการหากไม่ได้รับอนุญาต
6. จำกัดสิทธิผู้ที่เข้าถึง lead ใน Netlify และเปิด MFA สำหรับบัญชีผู้ดูแล
7. ตรวจสอบที่อยู่อีเมลแจ้งเตือน ความพร้อมให้ติดต่อกลับ และแนวทางลบข้อมูลเก่าตามนโยบาย

## ปรับแต่งค่าตอบแทน
แก้ `rewardPerInstallation` ใน `src/config.js` ระบบตัวเลขในหน้ารายได้จะเปลี่ยนตาม

## ขอบเขตของระบบ
- **มี:** หน้าแรก, ขั้นตอน, ข้อดี, คำนวณค่าตอบแทนตัวอย่าง, ฟอร์มส่งลูกค้า, ส่งเข้า Netlify Forms, FAQ, หน้าต่างประกาศข้อมูลส่วนบุคคล
- **ไม่มี:** บัญชีล็อกอินนายหน้า, ตรวจสอบสถานะเคสอัตโนมัติ, ระบบคำนวณค่าตอบแทนจากการติดตั้งจริง, การโอนเงินอัตโนมัติ, การตรวจสอบลูกค้าซ้ำอัตโนมัติ
- ระบบนี้บันทึกฟอร์มได้ แต่ผู้ดูแลต้องตรวจสอบงานและจ่ายค่าตอบแทนด้วยกระบวนการของตนเอง

## ไฟล์ที่สำคัญ
- `src/App.jsx` — หน้าเว็บและการส่งฟอร์ม
- `src/styles.css` — Tailwind + สไตล์เฉพาะ
- `src/config.js` — ข้อมูลติดต่อและค่าตอบแทน
- `index.html` — SEO และ static Netlify form definition
- `netlify.toml` — build + SPA fallback
